## 一、v54 新規則的副作用
| 規則 | 通過 | 新錯誤 |
|---|---|---|
| 生＋片假名→なま | 生チョコ、生ゴミ、生ジュース、生ワクチン、生コン；学生ハウス 不受影響 ✅ | — |
| を＋開く→ひらく | 心を開く、会を開く、ファイルを開く ✅ | ドアを開く 讀ひらく（口語多讀あける，可以接受） |
| 動詞／形容詞＋ことに 拆開 | 驚いたことに、残念なことに、幸いなことに ✅；ことによると＝說不定 ✅ | — |
| 名詞＋だと＋思う 拆開 | 私だと思った ✅；雨だと困る（條件）✅ | **彼だとわかった** 仍是「若是那樣」，規則只認「思う」 |
| 新增字典詞「ごと」＝連同 | 丸ごと、街ごと ✅ | **一日ごとに、国ごとに → 「連同…整個」**，應為「每〜」 |
| 新增字典詞「的」＝接尾 | 具体的、目的、的確 ✅ | **的を射る → 的(てき)**，應為まと；「射る」被切成「射＋る」 |
| 〜中 | 一年中、一日中、世界中、午前中 ✅ | **今週中 → 中(なか)**，應為ちゅう；体中 未收錄 |
| 何＋量詞 | 何人、何日、何階 ✅ | **何時間 → 何時＋間(あいだ)**；何年、何色 未收錄；何語 被切開 |

## 二、慣用語與歌詞常見詞（P0）
| 句子 | 顯示 | 正確 |
|---|---|---|

## 五、介面一致性
1. **側邊樹「情境小遊戲」落點是查頁挑選畫面**：麵包屑空白，見 00-彙整 P1-2。
2. **「繼續上次」標題退回成區名**：見 00-彙整 P1-3。
3. **寬螢幕 onboarding 時就有完整側邊樹**：使用者可以跳過程度與目的設定，直接進任何頁面。onboarding 時應該隱藏側邊樹，或把側邊樹設成 inert。
4. **今日課日檢結算「+0 XP」**：數字先顯示 0，動畫才跳成 30。如果截圖或停留時剛好在 0，會以為沒拿到 XP。改成從 0 開始動畫，但起始畫面先寫「+30 XP」。

## 六、結論
- v48–v54 的導覽重構沒有引入新的導覽錯誤，只有一個落點（小遊戲）與一個標題（繼續上次）要補。
- 語言上，v16 的 P0 都修好了，但「每修一條規則或新增一個字典詞，就有一個相反的用法被誤判」的模式還在：ごと、的、だと 都是。
- 建議：每次新增一個字典詞或規則時，同時寫 1 句「應該判成另一種」的反例進 `test-jptext`。例如新增「ごと＝連同」時，就加「国ごとに＝每〜」。
- 下一輪最值得做的兩件事：
  1. 歌詞頁等完整詞庫載完再畫。
  2. 補一批歌詞慣用語字典：せい、思い切って、さえ、気がする 等，約 30 條。
