# 3D 心智圖：資料來源與重建方式

## 來源與授權
| 資料 | 來源 | 授權 |
|---|---|---|
| N5–N1 詞彙清單（日文、讀音、英文釋義） | [open-anki-jlpt-decks](https://github.com/jamsinclair/open-anki-jlpt-decks)，源自 tanos.co.uk 的 JLPT 清單 | 專案 MIT；Tanos 清單 CC BY |
| 中文釋義、詞性、動詞類別、人事時地物、場景標籤 | 本站以 AI 加註（`tools/annot/out/n*.tsv`） | 本站 |
| 文法 748 條（句型、接續、例句、前置關係） | 本站以 AI 撰寫（`tools/annot/out/grammar-*.jsonl`） | 本站 |
| 3D 引擎 | [3d-force-graph](https://github.com/vasturiano/3d-force-graph) 1.80.1（內含 three.js），放在 `vendor/` | MIT |

JLPT 官方自 2010 年起不公布詞彙與文法清單，等級僅供參考。AI 加註的中文釋義與分類未經逐筆人工校對，發現錯誤請直接改 `tools/annot/out/` 後重建。

## 筆數
- 詞彙：N5 718、N4 668、N3 2140、N2 1809、N1 2699（跨級重複的詞只留在較低等級）。
- 文法：N5 88、N4 132、N3 179、N2 138、N1 211（跨級重複的句型只留在較低等級）。
- 任務：190 個（`data/mind/scripts.js` 的 5 個手寫腳本＋6 個樣板展開）。

## 重建
```bash
node tools/build-mind.mjs
```
讀 `tools/src/n*.csv`＋`tools/annot/out/*`，輸出 `data/mind/lex-n*.js` 與 `data/mind/grammar.js`，並列出欄位不合法、連結對不到的警告。改完記得把 `sw.js` 的 `VERSION` 加 1。
