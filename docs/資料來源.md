# 資料來源與授權

## 原則（必須遵守，`node tools/check-sources.mjs` 自動檢查）

1. **只用開放資料**：內建資料只能來自開放授權（CC0、公有領域、CC BY、CC BY-SA、MIT、Apache-2.0、BSD、Unlicense）或本站自編。不採用任何需要另外取得授權、付費、金鑰、會員登入，或只寫「保留所有權利」的資料來源。
2. **執行時連線也一樣**：App 只連開放授權的服務（維基媒體系列 API），不抓取新聞網站、歌詞網站、影片平台 API，也不用代讀服務。使用者自己貼上的文字、自己貼的 YouTube 影片（只用官方嵌入播放器播放）、自己的音檔，只存在使用者的裝置，不上傳、不散布。
3. **知識是公共財，要有多管道**：
   - 同一種知識至少提供兩條開放管道。例如詞義有本站詞庫，詞卡另附維基詞典（日／中）、維基百科、Tatoeba 連結；新聞有維基百科「最近の出来事」和維基新聞；閱讀有每日短文、維基百科、維基文庫。
   - 本站自編的內容以 **CC BY-SA 4.0** 釋出，任何人都可以再利用。
4. **標示出處**：CC BY／CC BY-SA 的內容，在畫面上標示出處與授權，例如文章頁的「維基百科・CC BY-SA 4.0」、歌曲頁的「歌詞：維基文庫・公有領域」。檔案開頭也寫明來源與授權。
5. **新增來源前**：先在下表登記名稱、網址、授權、用途，再接進程式。`tools/check-sources.mjs` 會擋下：
   - 程式裡出現沒登記的網域；
   - `data/` 底下沒登記的資料檔。

## 重建

```bash
node tools/build-mind.mjs                      # lex-n*.js、grammar.js（讀 tools/src、tools/annot/out）
node tools/build-fill.mjs <tomoshi.db>         # dict-fill.js
node tools/build-lex-ext.mjs <tomoshi.db> <zhtw ruleset.json>   # dict-big.js、senses.js、kanji.js
node tools/check-sources.mjs                   # 來源檢查
```
改完記得升版（見 CONTRACT.md「版本編號」）。原始資料（Tomoshi 約 690 MB）不入專案。
