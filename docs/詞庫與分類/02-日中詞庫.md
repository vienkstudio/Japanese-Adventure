### 2-2 結論

#### 推薦來源

1. **Tomoshi dict data（`zh_defs_zhtw`）——主力**。理由：唯一同時具備「JMdict 讀音＋詞性＋JLPT 等級」與「台灣繁體中文」的開放授權資料，前 4.1 萬常用條目經逐義項複審，不必簡轉繁。
2. **inakaegg/zh-ja-dict——備援、短釋義來源**。中文短，適合逐詞提示；但無讀音詞性，要用 JMdict（或 Tomoshi 本身）補讀音詞性，並把簡體轉繁。只拿來補 Tomoshi 缺的詞，或拿來縮短過長的釋義。
3. **JMdict 本體——骨架與校對**（讀音、詞性、活用類別、常用度 `news1/ichi1/spec1`），用來挑選要進站的詞，與決定動詞類別（五段／一段／サ變）。

#### 轉成 `dict-news` 格式（`表層|讀音|中文|詞性|類別|等級`）

1. 選詞：只取 JMdict 優先度標記（`news1`、`ichi1`、`spec1/2`、`nf01–nf24`）的條目（Tomoshi `is_common` 30,162 條）；再扣掉本站已有（lex-n*、dict-news、SUP）的表層。
2. 表層：取第一個 kanji 形（`keb`）；無漢字取 `reb`。寫法變體（`見積り／見積もり`）各出一行或交給 `variants()`。
3. 讀音：第一個 `reb`，轉平假名；外來語保留片假名、混寫複合詞維持現有慣例（`とうなんアジア`）。表層全假名時讀音欄留空。
4. 中文：取 `zh_defs_zhtw` 的前 1–2 義項，用「；」連接，**≤12 字**（逐詞提示用）；括號說明拿掉或移到 kb。
5. 詞性對照：`n`→n、`v5*`→v＋類別 1、`v1`→v＋2、`vs`／`vs-i`→n＋類別 s、`vk`/`vs-s`→v＋3、`adj-i`→i、`adj-na`→na、`adv`→adv、`exp`→exp、`prt`→part、`suf`→suf、`ctr`→ctr、`int`→int、`conj`→conj、`pn`→pron、`adj-pn`→pre；人名地名（JMnedict）→name。
6. 等級：用 Tomoshi／JMdict 的 JLPT 標記；沒有的依 `nf` 頻率分段（nf01–08→N3、09–16→N2、其他→N1）。
7. 產出分兩檔：`dict-news.js`（冷啟動，只放 ≤N3 與新聞／歌詞高頻詞）、新增 `dict-ext-n2n1.js`（完整模式才載），避免冷啟動變胖。
8. 在 `docs/資料來源.md` 加來源與授權表；產生器放 `tools/`，原始資料不入庫。

#### 簡體轉繁體

- 用 **OpenCC**（Apache 2.0，離線字典式）`s2twp` 設定：簡→台灣正體＋台灣慣用詞（例：数据库→資料庫）。Node 可用 `opencc-js`。

#### 風險

| 風險 | 說明 | 對策 |
|---|---|---|
| 授權（Share-Alike） | Tomoshi／JMdict／inakaegg／Wiktionary 都是 CC BY-SA：產出的詞庫檔須同樣 CC BY-SA 並標示來源；程式碼不受影響（EDRDG 明說使用其檔案的軟體不必開源） | 把匯入的詞放在獨立檔（例 `dict-ext-*.js`），檔頭寫授權與來源；與本站自編詞庫分開，避免把整份 lex 變成 BY-SA。lxl66566（來源不明）與商業辭典一律不用 |
| 檔案大小 | 冷啟動現在 ≈342 KB（conj 9＋N5 44＋N4 42＋N3 134＋dict-news 113），完整再 +288 KB。實測 dict-news 格式平均 46 bytes／行，1 萬行 ≈ 460 KB、全部 5.8 萬常用形 ≈ 2.7 MB | 冷啟動只加 ≤3,000 個高頻詞（≈120 KB）；其餘放完整模式或「點到未收錄才查」的分片檔（依首字分 50 片，每片 ≈10 KB） |
| 品質 | Tomoshi、inakaegg 都是 LLM 產生；常用 4.1 萬條有複審，長尾沒有。JMdict 義項排序以英文為主，取第一義項可能不是歌詞語境 | 只取有複審或常用度標記的條目；中文截短 ≤12 字；匯入後用 tools 跑「同字不同中文」「讀音欄異常」「簡體字」三項檢查；評審探針清單當回歸測試 |
| 斷詞副作用 | 詞庫變大可能讓最長匹配吃掉正確切法（如「がい＝害處」型錯誤） | 新詞成本設高於 lex（現在 dict-news 是「複合詞成本低於拆開」），全假名短詞（≤2 字）不匯入；匯入後跑 `test-cover` 與歌詞探針 |
| 一字多義 | 同表層多義（露、日中、大分、いくら）會更多 | 地名人名（name）另放、預設成本較高；多義詞保留現有 lex 的中文，只補缺 |
