# 03 歌曲翻譯分析：為什麼達不到「信、達、雅」（V3.3.0）

> 只調查、不改程式。實測用 node 載入 `js/jp-text.js`（完整模式 N5–N1＋dict-news＋場景＋文法），逐句跑 `JPText.tokenize`，照 `Reader.tokenParts` 的規則重現畫面上的逐詞中文。測試句為自擬、仿 J-pop 常見句型（不使用真實歌詞）。

## 1. 現在的翻譯流程

| 層 | 來源 | 程式 | 現況 |
|---|---|---|---|
| 整句中文 | **只有使用者手填**（編輯頁「中文翻譯」欄，一行對一句） | js/songs.js:215、235–261 | LRCLIB 抓到的歌詞 `zh:''`（js/link-import.js:401、js/songs.js:481）；大多數歌**沒有任何整句翻譯**，「中文」開關按了也沒東西 |
| 逐詞中文 | 詞庫第一義項，切在第一個「；，（」，**最多 8 字** | js/reader.js:319–321 | 只顯示辭書形的意思；活用（想要、過去、可能、假定、讓步）只有否定會加「不 」 |
| 文法提示 | `JPText.findGrammar` | js/jp-text.js | 只在點詞卡時看得到，不進逐詞列 |

結論：目前其實**沒有「翻譯」**，只有「逐詞查字典」。信、達、雅三層中：
- **信**（意思正確）：逐詞層錯誤多，見 §2。
- **達**（句子通順）：完全沒有。逐詞拼不出句意，也沒有整句翻譯。
- **雅**（有歌詞的韻味）：完全沒有。

## 2. 實測：逐詞列實際顯示什麼

| 句子 | 畫面逐詞（〔〕內＝顯示的中文；·＝助詞不顯示） | 應有句意 | 問題類型 |
|---|---|---|---|
| 君がいなくなった夜に | 君〔你〕 が いなくなった〔**空白**〕 夜〔夜晚〕 に | 你離開了的那個夜晚 | 補助動詞無中文 |
| 思い出す度に胸が痛む | …胸〔胸口〕 が 痛〔**未收錄**〕 む〔〕 | 每次想起都心痛 | **詞庫缺「痛む」** |
| 忘れられないあの日の約束 | 忘れられない〔**忘記**〕 あの〔那個〕 日〔**太陽**〕 の 約束〔約定〕 | 忘不了那天的約定 | 可能＋否定被吃掉、多義詞選錯 |
| 君のそばにいたかった | …いたかった〔**在**〕 | 好想待在你身邊 | 「〜たかった」（曾想要）沒譯 |
| 会いたくて会えなくて | 会いたくて〔**見面**〕 会え〔見面〕 なくて〔**沒有**〕 | 想見你卻見不到 | 想要、可能、否定全丟；切詞錯 |
| 抱きしめたいのに届かない | 抱きしめたい〔緊緊擁抱〕 のに 届かない〔不 **送達**〕 | 想緊緊抱住卻碰不到 | 「想」丟、「届く」選了物流義 |
| このまま時が止まればいい | …時〔**未收錄**〕 が 止まれば〔停止〕 いい〔好的〕 | 要是時間就此停止就好了 | **詞庫缺「時」**、假定「ば」丟 |
| 叶わない恋だと知ってても | 叶わない〔不 實現〕 恋〔戀愛〕 だ〔是〕 と 知って〔知道〕 て〔〕 も | 即使知道是不會有結果的戀情 | 「〜ても」被切開、だ＝是 |
| 笑ってたって心は泣いてる | 笑ってた〔笑〕 って 心〔心〕 は 泣いてる〔哭〕 | 就算笑著，心卻在哭 | 讓步「〜たって」被當引用「って」 |
| どうしようもないほど好きだった | …好き〔喜歡〕 だった〔**是**〕 | 喜歡到無可救藥 | 過去「だった」＝是 |
| 涙がこぼれそうで | 涙〔眼淚〕 が こぼれ〔溢出〕 そう で | 眼淚快要掉下來 | 樣態「そう」不顯示 |

### 2-1 歌詞高頻詞 168 個抽查

- **詞庫根本沒有（被切開或未收錄）9 個**：時、痛む、温もり、**落ちる**、淡い、素敵、（永遠に、何度も、ごめんね 被拆開，意思尚可）。
- **第一義項不合歌詞語境**：ただ＝**免費**（應為「只是」）、いつか＝**改天**（總有一天）、日＝**太陽**（日子、那天）、消す＝關掉（抹去）、迷う＝迷路（猶豫、迷惘）、愛しい＝可愛的（心愛的）、瞳＝瞳孔（眼眸）、届く＝送達（傳達到、碰得到）、思い＝想（心意、思念）、離す＝使分離（放開）。
- **名詞化「〜さ」譯成形容詞**：優しさ＝溫柔的、強さ＝強的、弱さ＝弱的、切なさ＝揪心的（應為溫柔、堅強、脆弱、揪心）。

### 2-2 根本原因：日檢詞表本身有洞

`lex-n*` 來自 open-anki-jlpt-decks（`tools/src/n*.csv`），與 Tomoshi 的 JLPT 標記比對，本站缺 **474 個** JLPT 詞：N5 36、N4 20、N3 37、N2 64、N1 317。缺的有很多最基本的詞：

- N5：足、川、終わる、風呂、丸い、昼ご飯、直ぐ、匹、枚
- N4：落ちる、落とす、回る、下がる、真ん中、喧嘩
- N3：頃、回、移す、下ろす、たった、年寄り、人ごみ、月曜～日曜

另外 時（とき）、痛む、素敵 連兩份來源都沒有。

## 3. 問題歸類

| # | 類型 | 影響 | 位置 |
|---|---|---|---|
| A | **沒有整句翻譯層** | 達、雅歸零；初學者看不懂句子 | songs.js（只吃手填 zh） |
| B | **逐詞只顯示辭書形意思** | 想要、過去、可能、被動、假定、讓步、樣態全部消失，句意反轉或模糊（忘れられない＝忘記） | reader.js:319–321（`FORM_ZH` 已有表卻沒用在逐詞列） |
| C | **多義詞固定取第一義項** | 日＝太陽、ただ＝免費、届く＝送達 | reader.js `split(...)[0]`、jp-text 詞條只存一個 zh 字串 |
| D | **詞庫缺基本詞** | 時、痛む、落ちる、足、川… → 未收錄或錯切 | data/mind/lex-n*（來源詞表有洞）|
| E | **語法組合被切開** | 〜ても、〜たって、会えなくて、いなくなった | jp-text 後處理規則只涵蓋部分句型 |
| F | **8 字截斷、詞性錯配** | 優しさ＝溫柔的、長義項被截 | reader.js:319、lex 中文欄 |

## 4. 改善方案（依投入排序）

### 4-1 「信」：逐詞層（不需外部服務）

1. **補詞**：用 Tomoshi（`zh_defs_zhtw`，CC BY-SA 4.0）補齊 474 個 JLPT 缺詞＋時、痛む、素敵 等，並加一份「歌詞高頻詞」小詞庫（約 2,000 詞）放冷啟動。做法見 `02-日中詞庫.md`。
2. **活用形加語意**：逐詞列用 `t.form` 組中文。
   - 〜たい＝想…
   - 〜たかった＝（當時）好想…
   - 可能＋否定＝…不了
   - 〜ば／たら＝要是…
   - 〜ても／たって＝即使…
   - 〜そう＝好像快要…
   - 〜なくなる＝不再…
   - 過去的だった＝（過去）是…
   - 例：忘れられない → 忘不了；会えなくて → 見不到（而且）。
3. **一詞多義**：詞條改存義項陣列；用前後詞挑義項，例如：
   - 日：前面是「あの／その」→ 那天。
   - ただ：在句首或接動詞 → 只是。
   - いつか：後接「〜たい」或意志形 → 總有一天。
   - 另做一張「歌詞語境優先義」表（約 300 詞），覆蓋字典第一義項：届く＝傳達到、瞳＝眼眸、消す＝抹去、迷う＝迷惘、愛しい＝心愛的。
4. **〜さ名詞**：「形容詞＋さ」規則化成名詞義（去掉「的」）。
5. **截斷**：8 字改成「取第一個完整義項」，過長才省略，且不切在括號中間。
6. **回歸測試**：本報告 §2 的句子、§2-1 的 168 詞做成 `tools/test-lyrics.mjs`，每次改斷詞都跑。

### 4-2 「達」：整句直譯（需要翻譯引擎）

| 選項 | 品質 | 成本／限制 | 建議 |
|---|---|---|---|
| ① 使用者貼翻譯（現有） | 看來源 | 使用者要自己找 | 保留；編輯頁加「從剪貼簿貼上整份」，並自動依行對齊 |
| ② 瀏覽器內建 Translator API（Chrome 桌面版，裝置端模型，ja→zh-Hant） | 通順，偏直譯 | 免費、離線、不用金鑰；行動版與其他瀏覽器支援度要實測 | **優先試做**：有支援就一鍵「產生整句中文」，存在該歌的 `lines[].zh`，並標示「機器翻譯」 |
| ③ 使用者自備 AI 金鑰（如 Claude API） | 最好，可要求「直譯＋意譯＋註解」 | 純前端要讓使用者輸入自己的金鑰；有費用 | 進階選項，放設定頁 |
| ④ 雲端翻譯 API（Google、DeepL） | 通順 | 要金鑰與後端，免費額度有限 | 不建議（本站無後端） |

### 4-3 「雅」：意譯與註解

- 只有 4-2 的 ③（或人工翻譯）做得到：一句給兩行，**直譯**（對應逐詞、學文法用）＋**意譯**（像中文歌詞）。若有修辭（倒裝、省略主詞、擬聲、季語），在詞卡註解。
- 介面三層切換：逐詞（信）／直譯（達）／意譯（雅），預設依程度選：零基礎看意譯＋逐詞，N3 以上看直譯。

### 4-4 版權注意

整句翻譯只存在使用者自己的 IndexedDB（現行做法），不上雲、不內建。介面標示「個人學習用」。本站不散布歌詞或譯文。

## 5. 優先順序建議

| 順序 | 項目 | 預期效果 |
|---|---|---|
| 1 | 補 474 個 JLPT 缺詞＋時、痛む、素敵（Tomoshi） | 未收錄與錯切大幅下降 |
| 2 | 逐詞列加活用語意（4-1-2） | 「忘記→忘不了」這類意思反轉的錯誤消失；**信**大致達標 |
| 3 | 歌詞語境義項表＋多義規則（4-1-3、4-1-4） | 日、ただ、届く 這類誤譯消失 |
| 4 | Chrome Translator API 整句直譯（4-2-②） | **達**：免費機器翻譯 |
| 5 | 自備金鑰的直譯＋意譯（4-2-③、4-3） | **雅**：只有這條路做得到 |

## 6. 參考：Marumaru（marumaru-x.com）的做法

- 每句顯示：日文（振假名）→中文整句→英文整句，外加逐句播放、重複、A-B 循環。
- 沒有逐詞中文、文法或活用說明，點詞也不會跳詞卡。
- 譯文偏意譯（四字詞、改寫雙關）。頁面標示譯文「轉自」某 YouTube 影片，由人工翻譯，也就是說「雅」來自人工整句翻譯。
- 對本站的意義：Marumaru 強在「達、雅」（整句），本站強在「信」（逐詞＋活用）。兩者可以疊在一起：逐詞列（本次已加活用語意）＋整句列（§4-2 的機器或使用者翻譯）。

## 8. 第二輪：大詞庫、多義、音讀／訓讀（V3.3.0 之後，未提交）

- **大詞庫** `data/reading/dict-big.js`：JMdict 常用詞中本站沒有的 19,870 詞，每詞最多 3 個義項，1.2 MB（gzip 約 0.5 MB）。
