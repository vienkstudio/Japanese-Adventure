## 新 API（core）
- `App.guardBack(onBack, onDrop)` → release()：活動進行中攔截頂列 ← 和手機返回鍵。popstate 時會補回這一筆紀錄，停在原頁；換頁時呼叫 onDrop。
- `App.backTo(name, params)`：上一筆就是該頁時用 history.back，否則換掉目前這筆紀錄再重繪。
- `App.replaceEntry(name, params)`：只換掉目前這筆歷史紀錄，不重繪。
- Activity opts.back 新增 `false`：離開時不跳頁，交給呼叫端處理（今日課內嵌時用）。
