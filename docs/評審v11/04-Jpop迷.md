## 3. 新發現
1. **【高】路線熱門歌點下去「找不到這首歌」**（見上）：唯一像「歌曲路線」的入口反而壞掉。建議 path 改走 lookup 的匯入流程，或 songs.js 匯出 `importHot`。
2. **【高】第一堂今日課 0 個歌詞詞**：歌曲目的第一天新學全是「浅草はどの電車」「銀座線」等旅遊句（`06`）。`funFresh` 沒唱過歌時從 daily 短文取；建議首日直接拿熱門第一首（アイドル）的歌詞詞。
3. **【中】第二堂：複習剛做完「秘密」，新學第 1 張又是「秘密」**（`29`→`30`），重複。
4. **【中】今日課仍是舊字卡**：複習卡「忘了／記得／很簡單」3 鈕，測驗答對不自動跳（G1 新框架只用在路線）；一堂 6＋6 約 20 下。

6. **【中】首頁「去用出來」先進結算頁再按一次才到歌**（多 1 下）。
7. **【中】路線「歌曲新聞」第一屏是短文，建議下一個是「示範曲（自編童謠）」**；對 J-pop 迷應熱門歌在前。私の朝 句子已在今日課學過，卡片仍顯示「還沒做」。
