4. 路線排句子詞塊切錯：「見といてね」切成 見と｜いてね，「、」單獨一塊（截圖 33）。
5. 路線「選選看」標 5 題實際 3 題；答錯時「✗ 正確答案」文字被固定的「繼續」蓋住（截圖 30）。
