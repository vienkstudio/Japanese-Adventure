## 修正清單（依共識）
### R 閱讀／歌曲／斷詞（js/jp-text.js、js/reader.js、js/link-import.js、js/songs.js、css/reader.css）
1. 簡單日文新聞標題露出 `<ruby>` 原始碼、顯示「717 天前」與「近三天」矛盾。
2. 斷詞教錯：米国→米、兆→きざし、打ち合わせ拆開、差し引く→差す、半導体拆開、ない→有、だらけ→毛髮、こわばる→孩子；完璧、紅蓮、走馬灯、エリア 無讀音。補新聞／歌詞常見複合詞字典、長詞優先、不認得的漢字詞不要硬拆成錯義單字。
3. 本文文法：依使用者程度排序與過濾（N3 以上只列 N3+）、誤判（によりますと≠より、からの≠N1「多達」、駅には≠〜には（目的）、輸出から≠理由）。
4. 「讀完了」埋在約 6000px 下方 → 放到正文後、清單前，並在頂部常駐。
5. 翻唱網址抓錯歌（まふまふ 紅蓮華 → 命に嫌われている）：歌名必須相符才採用。
6. 填空「對答案」把沒填的格子當錯並加進不會清單 → 未作答不算錯、不加入。
7. 首頁可「繼續上次那首歌」。

10. 點品項後面板蓋住「叫店員」。
