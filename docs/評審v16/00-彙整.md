## 新問題

### P0：會教錯

**N0-1. 生ビール、日本酒在 App 裡仍讀錯（v15 P0 沒修好）**
- 位置：`js/jp-text.js:545` 的 `ready()` 只載入 `lex-n5～n3`＋`dict-news`。複合詞「生ビール」「日本酒」只存在場景資料裡，冷啟動的斷詞看不到。
- 為什麼沒被抓到：`tools/test-reading.mjs` 額外載入 `scenes-1/2`、`cards`、`daily`，所以會過。
- 改法：
  1. 把旅遊常用複合詞寫進 `dict-news.js`，例如生ビール、日本酒、生卵、生ハム、生クリーム、生放送。
  2. 另加規則：「生」後面接片假名或食物詞時讀なま。
  3. `test-reading` 改成只載入 `ready()` 會載的檔案。

**N0-2. 歌詞逐詞中文誤切，畫面直接顯示錯的意思**（09，《猫》）

| 原句 | 顯示 | 正確 |
|---|---|---|
| 君がいなくなった | が＋い 被切成「**がい＝害處**」 | が（助詞）＋いなくなった（不在了） |
| そうはいかない | そう＝**是的**、いかない＝**不 去** | 慣用句「沒那麼容易／不能那樣」 |
| 馬鹿馬鹿しい | 馬鹿／馬鹿／しい＝**強迫** | 一個形容詞「荒謬的」 |
| 幻だと思おう | だと＝**若是那樣** | 引用的「と」 |

- 位置：`jp-text.js` 的 `tokenize`。
- 改法：
  1. 「が＋い（る）」優先判成助詞＋いる。
  2. 補慣用句「そうはいかない」，以及 AA しい 疊詞形容詞。
  3. 「だと」接在名詞後面、下一個是思う／言う時，判成引用。
  4. 把上面這些句子加進 `test-jptext`。
