| 句子 | 顯示 | 正確 | 原因 |

## 四、學習 id
- ✅ 7,995 個詞 id 沒有「不同讀音共用 id」（test-lexid）。瀏覽器內確認：`v:開く`／`v:開く|ひらく`、`v:辛い`／`v:辛い|つらい`、`v:一日`／`v:一日|ついたち`、`v:九|く`、`v:十|とお`。
- ❌ **同讀音、不同義仍共用 id**：「キロ（キログラム）」與「キロ（キロメートル）」都是 `v:キロ`。學了公斤，公里就不會再出現。改法：同字面同讀音時，id 加義項序號，例如 `v:キロ#2`。

### 新發現（P1）：「〜ことに」一律被當成副詞「尤其」
| 句子 | 顯示 | 正確 |
|---|---|---|
| 行くことにした | ことに＝**尤其** | こと＋に＋する＝決定〜（N4 文法） |
| ならないことに驚く | ことに＝**尤其** | こと＋に（對〜感到驚訝） |
| 食べたことに気づいた | ことに＝尤其；**気／づ／いた** 拆成三塊 | こと＋に；気づく 是一個詞 |

- 「〜ことにする／ことになる」是 N4 必考文法，文章頁和歌詞會直接顯示「尤其」。
- 改法：
  1. 前一個詞是動詞或形容詞的連體形時，「ことに」拆成 こと＋に，只有句首或接在名詞後才當副詞。
  2. 「気づく」連用形（気づいた、気づいて）收進字典。
  3. 把上面 3 句加進 `test-jptext`。
- 另外：「持ち帰らなければならない」的「ならない」逐詞顯示「變成」，應改為文法「必須」（なければならない）。
