## 共識問題

### P0：會教錯、卡住
1. **歌詞斷詞誤譯被當成今日課的正解**（09）
   - 現象：今日課教「そう＝是的」。原句是「飲み込んでしまいそうな」，這裡的そう是樣態助動詞，意思是「好像要…」。
   - 原因：`js/learn.js:338` 的 `songWords` 只檢查 `t.known && POS_OK`，沒看前後文。
   - 改法：前一個 token 是動詞連用形（或形容詞語幹）時，跳過そう／すぎる／やすい；前一個是て形時，跳過しまう／いる／おく／みる／くる／いく。函式詞（そう、よう、こと、もの）不當單字出題。`POS_OK` 也要排除單獨的 `adv` そう。
2. **京都清水寺任務的敘述和條件矛盾，單元句完全用不到**（05）
   - 現象：任務寫「兩大一小、買大人×2 小人×1」，下方「旅伴想要」卻是「兩個人・全部是大人」。店員也沒問人數，剛學的「二人です／大人だけです」沒機會用。
   - 原因：`js/world.js:1209` 只有在原條件存在而且值不同時才把 `changed` 設成 true。family 任務原本只有 `pay`，新增的條件不算改動。
   - 改法：`o.prefs[k] == null` 時也算 `changed`。`changed` 而且是 `q`（固定任務）時，改用 `g.items`／隨機品項，或先排除跟 alt 衝突的任務，例如含 `kodomo` 的任務不能配 `大人だけ`。另外要確認 checkout 一定會問到 alt 對應的問句（`S.asks` 依 alt 排前面）。
