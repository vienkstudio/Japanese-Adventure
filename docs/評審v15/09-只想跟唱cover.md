## 二、新發現
1. **P0｜歌詞斷詞誤譯被當成今日課正解**：`js/learn.js:338` `songWords` 只看 `t.known && POS_OK`，`しまいそう` 的「そう」（樣態助動詞）被當成副詞「そう＝是的」收進 `v:そう` 並出題。同一批還有「しまう（…完、不小心…）」。
2. 高｜翻唱標題解析錯（`js/link-import.js:221` `coverParse`）：「【歌ってみた】DISH// - 猫 / THE FIRST TAKE ver. 【北村 匠海】うた：たすくこま（豚）」→ 翻唱者「【北村 匠海」；「猫 -DISH//歌ってみた【ふうはや】」→ 原唱「k k」。另 LRCLIB 對錯誤候選 `track_name=DISH` 回 429。
3. 中｜`js/songs.js:832` 填空 0 分時不能按「練完這首」，提示文字誤導。
4. 中｜歌詞沒有整句翻譯（只有逐詞），英文括號行混在歌詞裡被挖空。

**最想要卻找不到**：同一首歌不同翻唱的「對時」能共用；整句中文。
