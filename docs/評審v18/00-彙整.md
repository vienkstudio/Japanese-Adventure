## 共識問題
### P0
1. **新聞點進去不是那則新聞**（01、02、03、04、05、06、07）：取「連結文字最長」的條目，開成整篇維基條目（沖縄県 3.5 萬字、頁高 14 萬 px）（`js/link-import.js:388-391`）。維基新聞最新一則 205 天前、多為兇案；文末情報源混進本文（`link-import.js:72、396`）。
2. **受著作權保護的流行歌歌詞在公開 repo**（10）：`tools/test-jptext.base.txt:641-1033` 收了 99 行（紅蓮華、アイドル）；`check-sources` 不掃 tools／docs，也沒擋任意 https 音訊串流。**違反「只用開放資料」，且已推到 GitHub 歷史。**
3. **多義詞卡把同音同形的別的詞當本詞**（06、10）：4,249 個多義詞有 357 個（8.4%）第一組義項錯（と→十／外面、この→九、何、彼 首義低俗）（`tools/build-lex-ext.mjs:149-161` 沒依讀音詞性過濾）；「也可能是」列出自己或重複（`js/jp-text.js:942`）；側、裏 混入他讀義項（`senses.js:143、746`）。
4. **公有領域歌曲**（01、04、08、10）：15 首中 ちょうちょう、シャボン玉、蛍の光 打不開，浜辺の歌 抓到說明文字，証城寺、故郷の空 混入作者資訊；歷史假名遣、舊字體未處理（さくらさくら：かむ→咬、いざ→一旦、櫻／彌生／霞 未收錄、〳〵 原樣）；離線打不開。
5. **N1 讀音題假字**（06，v17 已回報）：200 題 25 個干擾項不合發音（かんっしょう、せっぢ）（`js/challenge.js:247、254`）。
6. **其他會教錯**（10）：名詞＋まで 無から 一律判「甚至」（`jp-text.js:1063`）；二十日 中文「八」（`lex-n5.js:538`）；十分後→じゅうぶん；迷惑をかける 的かけ→打電話；引用と→和（`jp-text.js:855`）。
