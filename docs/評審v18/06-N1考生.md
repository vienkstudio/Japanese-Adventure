## 3. 新發現
1. **讀音題有唸不出來的假字**：
   - 實際操作 10 題 N1 單字中有 4 題讀音題，其中 2 題有不可能的假名：干渉 → かんっしょう、送金 → そうっきん。
   - 用 `Challenge.makeQuestions('N1','kanji',20)` 抽 200 題（600 個干擾項），有 25 個違反音韻規則，約每 8 題就有 1 題：
     - っ 接在ん後：そんっしつ、じゅんっきゅう、うんっちん。
     - っ 接在長音後：かいっそう、ゆうっせい、とうっそう、こうったく。
     - 濁音前加っ：せっぢ、けっぜい、つっづく。
     - 拗音被換掉：いっきゅに。
   - 考 N1 的人一眼就能刪掉這些選項，四選一實際上變三選一。
   - 原因：`js/challenge.js:254` 加っ時沒有排除前一字是ん、長音（う、い、ー）的情況；`:247` 清濁互換後沒有排除「っ＋濁音」。
   - 改法：`mutate()` 最後加一道過濾 `/[んうーい]っ|っ[がぎぐげござじずぜぞだぢづでどばびぶべぼなにぬねのまみむめもやゆよらりるれろわん]/`（像「いっ」這種合法組合可以保留）。
2. **文脈規定的干擾項不成詞**：「お立ち（　）ください」的選項是 寄り／合せ／営／様。営、様 是單字碎片，不像 N1 的選項。其他兩題文脈規定（形勢、成り立つ）的品質不錯。
3. **詞卡「也可能是」列出自己或重複**：
   - 姿勢 →「也可能是：姿勢（姿勢）」；応じる → 応じる；営業 → 営業；強いられて →「強いる（強迫）、強いる（強迫）」。
   - 原因：`js/jp-text.js:942` 只用 `x.e !== e` 比對物件，沒有比對 jp＋kana，所以大詞庫和本站詞庫各一筆同一個詞時，會重複列出。
4. **多義詞卡把其他讀音的義項混進來**：
   - 側（文中唸がわ）的「意思」只列出 そば／かたわら 的義項，沒有がわ（`data/reading/senses.js:143` 缺がわ）。
   - 裏（文中唸うら）另外列出 うち 的 5 個義項，うち 寫成「裏」是罕見寫法（`senses.js:746`）。
   - 建議：只顯示和本詞讀音相同的義項，其他讀音收合。
5. **羅馬字有錯**：察し 寫成 sashi，應為 sasshi（漏了促音）；確か 寫成 tashi ka（多切了一刀）；見直したり 寫成 minao shitari。
6. **新聞（維基）**：
   - 第一次進「閱讀・新聞」顯示「新聞來源暫時讀不到」，按 🔄 後才有資料。實測當下維基 API 回應 200，問題可能出在第一次請求逾時太短。
   - 標題本身是很好的 N1 讀解素材，例如「COP31 が閉幕。脱化石燃料での合意ができず…」。但點進去開的是人物條目全文：點 NVIDIA 那則，開的是〈ジェンスン・フアン〉條目，8066 字，不是那則新聞。建議改成先逐詞拆解標題句，再附「看相關條目」連結。
   - 新聞內文斷詞錯誤：「純資／産額」，應為「純資産／額」。
7. **模擬考的聽解選項用到讀過的文章**：選項取自剛讀過的〈おもてなし再考〉中文翻譯，讀過的人會覺得是送分題。30 題、20 分鐘、分科基準點判定，形式不錯。
