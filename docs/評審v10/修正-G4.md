## 交接
- **G1（activity.js）**：shop 步驟回傳 `meta.left:true`／`done:false` 時，建議結算不要算這一步完成（目前 runner 遇到空 results 會直接跳下一步）。
- **G2（path.js）**：
  - 單元星數和「已學 n／總數」目前用字卡紀錄來算，中途離開實戰仍可能顯示 ★ 和 8／8。建議星數也要看 shop 步驟的 `meta.done`，或看 `App.stars('w:<店>:q-…')`。
  - 依地區挑實戰店時，直接把店 id 放進 `params.shop` 即可，京阪 12 間都可以當實戰店。
- **Phrase 擁有者**：`Phrase.romaji('かーど')` 回傳 `kado`（平假名的「ー」被吃掉，片假名カード是 kaado）。
- 已知小差異：貨架結帳那句組句是 Phrase 產生的「これをお願いします」，不是單元句「これください」（組句模型由 Phrase.make 決定，這次沒動）。
