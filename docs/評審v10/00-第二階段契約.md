# 第二階段契約（路線＋活動框架＋合併重複）

依據：`docs/評審v8/00-總指揮架構分析.md` §4、§5 階段 2；`docs/評審v9/00-彙整.md` B 段；`docs/交接prompt.md` 的使用者決定與停損規則（**3D 保留、舊模組留在經典練習、不新增地區店家 3D 功能、不擴充手寫字典、不寫同步橋、一律 `Learn.record`、首頁不加按鈕**）。

## 1. 資訊架構
- 底部導覽 4 鈕：`home` 今天（1）、`path` 路線（2）、`lookup` 查（3）、`me` 我的（4）。其他路由一律 `nav:false`，以 `navParent` 指向這 4 個之一。
- 原本的 `play`、`read`、`kb`、`review` 從導覽拿掉：
  - `play`（冒險）、`challenge*`、`boot*`、`biz*`、`classic`、`cards` → navParent `path`
  - `read*`、`songs`、`song`、`kb*`、`mind3d`、`phrasebook` → navParent `lookup`
  - `review`、`settings` → navParent `me`
- 舊路由保留可用（深連結不壞），只是不再是導覽入口。

## 2. 活動框架（G1 組，`js/activity.js`＋`js/activities/*.js`＋`css/activity.css`）
```js
Activity.register(type, { start(el, ctx) -> Promise<{results:[{id, grade}], meta?}> })   // grade 0 忘了、1 困難、2 記得、3 簡單
Activity.run(el, { type, items, params, title, back:{route, params} }) -> Promise<summary>
  // 一題一屏、頂部進度條；結束統一結算畫面（學會 N 個、答對率、明天到期 M 個、連勝）
  // 每個 result 由 runner 呼叫 Learn.record(id, grade, {src: title})；活動本身不得呼叫 Learn.record
Activity.session(steps) -> 依序跑多個活動（例：flashcard → choice → shop），最後只顯示一次結算
```
- Item 格式＝`Learn.view(id)` 的回傳：`{id, type:'kana'|'vocab'|'phrase'|'grammar', jp, kana, zh, romaji?, ex?:[{jp,zh}], lv, source}`；讀音缺時用 `JPText`／`Phrase.romaji` 補。
- 內建活動：
  - `flashcard`：正面日文（可切中文先）、翻面讀音／羅馬字／中文／例句／外來語原文（`Loan`）、語音；自評 4 鍵。取代字卡頁與今日課卡片。
  - `choice`：看日文選中文／看中文選日文／聽音選字／JLPT 文法形式；干擾項同型別同等級、唯一正解；N3 以上作答前不附中文。取代挑戰的出題核心（挑戰的題庫邏輯可搬進來）。
  - `wordbank`：排詞塊組句（沿用 `Phrase` 的分詞），可接受多種詞序。
  - `listen`：聽語音選意思／選字／數字快打；取代特訓 drill 的出題形式（特訓題庫 `data/drills.js` 為資料來源）。
  - `shop`：交給冒險引擎（G4 組提供 `World.shopSim(el, {shop, goal})` → Promise<results>）。
- 路由 `act`（navParent `path`）：`App.go('act', {unit})` 由路線頁呼叫，或 `{type, ids}` 直接跑。

## 3. 路線頁（G2 組，`js/path.js`＋`css/path.css`）
- 路由 `path`（導覽 2）、`path-unit`。頂部分頁依使用者目的（`App.profile().goals`）：旅遊／日檢／商務／歌曲新聞；零基礎（`lv:'zero'` 且未學完假名）最上方固定「五十音路線」。
- 單元資料在執行時由現有內容組出（**不新增店家、地區**）：
  - 旅遊：49 間店依店型歸成約 14 個場景包（便利商店、餐廳、拉麵、居酒屋、咖啡、藥妝、購物、車站與交通、機場、飯店、觀光寺社、緊急醫療、市場、租車與自駕…），每包 6–8 句必備句（來源：店家的句型／店員問句／手冊同分類）→ 步驟 flashcard → wordbank → shop。
  - 日檢：N5–N3（N2／N1 先列出但用現有挑戰）每單元 20 詞＋3 文法（來源 `MIND`，依 core 標記與頻率排序）→ flashcard → choice → 單元小考；每級最後一格「模擬考」（沿用 `challenge` 的模擬考）。
  - 五十音：清音分 10 行、濁音、拗音共 12 個單元，用 `kana-lesson` 的講義內容當單元說明＋flashcard＋listen＋choice。**這是唯一的五十音入口**（首頁零基礎今日課、手冊五十音分頁都導來這裡）。
  - 商務：直接列 `BIZ` 8 單元，點了進 `biz-unit`（G2 不改 biz.js）。
  - 歌曲新聞：熱門精選歌曲、今日短文、近三天新聞的入口卡（點了進 `song`／`read-article`／`read`）。
- 單元卡顯示：已學 n／總數、星數、下一個建議單元高亮；第一屏可點 ≤25。
- 首頁今日課的「新學」改從目的路線的下一個單元取（G2 提供 `Path.nextUnit(goal)` → `{id, items}`；`learn.js` 的 queue 呼叫它，存在才用，不存在退回原規則）。

## 4. 查與我的（G3 組，`js/lookup.js`、`js/me.js`、`css/lookup.css`）
- `lookup`（導覽 3）：最上方一個搜尋框（跨手冊句子、MIND 詞彙文法、外來語、我的文章歌曲）；下方依目的的工具卡：旅遊＝快查手冊（🆘 緊急置頂、大字給店員看）、日檢／商務＝字典與文法（知識庫）、歌曲新聞＝閱讀、歌曲、我的文章；另有「🧠 3D 心智圖（實驗）」「🔗 匯入網址（實驗）」小入口。
- `me`（導覽 4）：今日到期與複習（進 `review`）、已學會統計（依 Learn 狀態分類）、連勝與成就、御朱印帳、設定、🏯 經典練習、備份。
- 手冊的五十音分頁改為導到五十音路線（kana-lesson 內容由 G2 使用）。

## 5. 冒險降級為 shop 活動（G4 組，`js/world*.js`、`css/world.css`）
- 新增 `World.shopSim(el, {shop, goal, items})`：直接進店、只顯示與目前目標相關的區域與按鈕（第一屏可點 ≤12），完成子目標後 resolve `{results:[{id,grade}]}`（不自己呼叫 `Learn.record` 以外的進度；現有 `App.reward` 星數可保留）。
- 自由逛的 `play` 地圖保留（在路線旅遊分頁底部「自由逛日本」）。
- `World.shopsByType()` → `{type: [shopId…]}` 給 G2 組場景包用。

## 6. 主對話（整合）
- `index.html` 導覽與 `Home.lazy` 登記、`sw.js`、`CONTRACT.md`、`js/home.js` 的導向（零基礎→五十音路線、今日課新學→`Path.nextUnit`）。
- 驗收：每種目的首頁到第一個新東西 ≤2 次點擊；一個單元 ≤15 次點擊、≤10 分鐘；任一頁可點 ≤25；導覽 4 鈕；375px console 0 錯誤；回歸測試全過。
