# 評審 v3-02：冒險世界遊戲設計（對抗式）

實玩：線上版 375×812，首頁 → 繼續冒險 → 成田機場街區 → 空港ターミナル → 委託 → 案内所 → 組句。
**評分：簡單明瞭 3/10、想玩下去 2/10。**

## 0. 實玩看到的硬傷（先修）
- 街區／店內地圖只佔中間一小塊，上下各 1/4 是灰色空框；`fit()` 取 `min(寬/欄, 高/列)`，直式螢幕必然留白（`js/world.js:89-92`、`css/world.css:55`）。
- 首次進街區／店自動彈 86% 高說明面板，地圖整個被蓋（`js/world.js:645`、`:725`、`css/world.css:92-94`）；店員面板也蓋掉全圖，看不到自己在哪。
- 🪧（Emoji 13）在 Win10／舊 Android 顯示成 ⊠ 方框（`js/world.js:619`、`:632`、`:658`）。
- 店名在 HUD 被截成「空…」，HUD 4 顆按鈕（委託／圖鑑／籃子／N5）意義不明。

## 1. 核心循環與為何不好玩
現況循環：選地區 → 走格子 → 進店 → 開委託板 → 讀任務單 → 走到貨架/店員 → 開面板 → 選意圖 → 排詞塊 → 店員回話 → 結算星星 → 回委託板。
問題：
1. **行走是純成本**：點目的地後角色自動尋路，玩家沒有任何決策；格子地圖只是「選單的低效版本」。
2. **對話被拆成表單**：選意圖 8 宮格 → 詞塊，沒有「人在講話」的感覺；N5 直接把答案印在詞塊上方（`js/world.js:227`），變成抄寫。
3. **沒有好奇心鉤子**：每間店 = 同一套 12 個委託模板（`js/world-quest.js:20-28` tour/rand/checkin/ask/read/talk/ev），換店不換玩法。
4. **獎勵抽象**：⭐、XP、御朱印計數，與「我會說的話變多了」無連結。
→ 應改成：**場景（看到情境）→ 一句話挑戰（說對）→ 即時後果（店員反應、拿到東西、劇情推進）→ 收集（句卡）**，30 秒一輪。

**建議：自由探索＋收集驅動（類《動物森友會》圖鑑／《Pokémon Go》圖鑑）**

## 3. 店內場景：方案比較
| 方案 | 質感 | 工作量 | 375px 適配 | 資料改動 | 評 |
|---|---|---|---|---|---|
| A. 保留格子、換 CSS 貼圖 | 低→中 | 中 | 差（留白、太小） | 無 | 治標 |
| B. 等角 2.5D（CSS transform/SVG） | 中高 | 高（物件要逐一畫、深度排序） | 差（菱形更浪費寬） | 大 | 不划算 |
| C. 整張 SVG 插畫房間＋熱點 | 高 | 高（49 店各畫一張） | 好 | 大 | 太貴 |
| **D. 場景卡＋視覺小說式對話** | 中高 | 低中 | 最佳 | 小（沿用 zones/items） | **推薦** |

**推薦 D**：每種 `kind`/`scene` 用 1 張程式生成的 SVG/CSS 背景（約 8 種：便利商店、餐廳、櫃台、車站、神社、藥妝、市場、戶外），疊上：
- **背景層**：CSS 漸層＋SVG 幾何（地板透視線、牆、貨架剪影、暖簾、燈籠），依 `kind` 換配色；共用元件畫一次可用於 49 店。
- **熱點層**：zones 轉為 3–6 張橫向「場景卡」（貨架、收銀台、座位、看板），卡片＝大圖示＋日文名＋圓角陰影，不再是 1 格 emoji。
- **角色層**：店員用 CSS 剪影＋大 emoji 臉＋名牌（例：コンビニ店員），底部對話框（打字機效果、🔊、說話者名）。
- 看板用既有 `signHTML`（`js/world.js:596-597`）真實配色，這是目前最有質感的元件，擴大使用。
- 🪧 一律改 CSS 畫的看板，不依賴新 emoji。

## 4. 程度分級 N5–N1
現況：只改「是否顯示讀音／中文」「詞塊干擾項數」「N3+ 賣完事件」「N2+ 敬語」（`js/world.js:23`、`:221-222`、`:420-421`、`index.js:5-11`）。玩家感受：**換了只是變難且進度歸零**，沒有理由切換。
建議：
- **移除全域程度切換**，改為「**每句話的難度星**」：同一個情境提供 3 種說法卡——基本（N5）／禮貌（N4–N3）／敬語（N2–N1），玩家當下自選；選越高階、獎勵越多（1/2/3 枚硬幣）。
- 提示改為**單句可點開**（已有 `wd-peek`），不靠程度一鍵關閉。
- 店員回話難度依「玩家最近 10 句平均階」自動微調（隱形 DDA），不需玩家理解 N 級。
- N 級只顯示在**句卡圖鑑**上當標籤（「你已收集 N4 句 23/80」），作為成長證明而非門檻。

## 5. 點擊數、回饋、獎勵節奏
實測：從首頁到說出第一句日文 ≈ 9 次點擊＋讀 2 個大面板（繼續→關說明→點建築→等走路→關說明→委託列→選委託→出發→點店員→點委託→排 4 塊→說出來）。
目標：**首頁 → 第一句日文 ≤ 3 點、≤ 15 秒**。
- 回饋：答對＝店員表情變化＋動作（遞東西動畫）＋語音；答錯＝店員歪頭「え？」＋給下一層提示，不扣心、不記失誤次數給星。
- 節奏：每 30 秒一個小獎（句卡入袋）、每店 3–5 分鐘一個中獎（印章＋店的小故事完結）、每街區一個大獎（街區明信片 SVG）。
- 取消 3 星評分壓力；改「句卡收集率」與「連續答對 combo」。

## 6. 重設計規格（可直接實作）
**畫面 A：街區（取代格子地圖）**
- 直式滿版：上方 56% 為街景 SVG（橫向可左右滑的長捲軸，店面＝立面卡片：屋頂色帶＋暖簾＋招牌字＋emoji），下方 44% 為「這條街」清單。
- 點店面 → 直接進店（0 走路動畫）；景點／NPC 為街上浮動氣泡。
- 刪除首次自動說明面板，改店面上 1 行 tooltip。
**畫面 B：店內**
- 結構：`[HUD 48px：← 店名(不截斷) 句卡數] [場景 45%：背景＋店員＋熱點卡] [對話框 / 動作區 55%]`；不再用 bottom sheet 覆蓋。
- 進店即觸發店員開場白（いらっしゃいませ）＋ 3 個「你想…」大按鈕（例：買東西／問問題／四處看），= 第 1 點。
- 選「買東西」→ 熱點卡橫捲（貨架），點商品 = 放進籃子（第 2 點）→ 到收銀台自動進入對話。
- 每句話：3 張說法卡（基本／禮貌／敬語），點一張後進入**排詞塊（只在第一次用某句時）**，之後同句改為「聽→選」快速回合（第 3 點即開口）。
**流程規則**
- 任務＝店內右上「今日想做的事」3 條，自動在玩家行為中勾選，無需接取、無放棄、不清籃子。
- 任何一條完成即蓋本店印；全部完成解鎖「常客對話」彩蛋。
- 地區全開；日本地圖節點顯示「已收集句卡 n/總數」。
**資料改動（最小）**
- `data/world/index.js`：刪 `need`，或保留但引擎忽略；新增 `scenes:{kind→背景 id}`。
- shop：沿用 `zones/items/asks/acts`；新增選填 `lines.polite/keigo` 供三階說法；無則由 `Phrase.make` 依 lv 生成三版。
- 引擎：`buildMap` 保留給「問路」小遊戲，其餘頁面改 `renderScene()`；存檔 key 去掉 `@lv`（舊資料取各 lv 最大值遷移）。
**驗收**：375px 無灰色留白；首頁→第一句 ≤3 點；無任何 🔒；無 ⊠ 方框；換說法不影響進度。
