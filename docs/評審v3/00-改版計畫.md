## 共用契約（四個工作組都必須遵守）

### 1. 主題與色票（A 實作，B/C/D 只用變數）
- 新檔 `css/tokens.css`，在 `css/app.css` 之前載入。
- `<html data-theme="light|dark" data-palette="coral|sakura|matcha|ocean|lavender|mono">`；`data-theme` 未設＝跟隨系統（`@media (prefers-color-scheme:dark)` 套到 `:root:not([data-theme=light])`）。
- 變數名沿用現有：`--bg --card --chip --text --muted --line --line2 --pri --pri-d --pri-t --acc --acc-d --acc-t --gold --r --shadow --shadow2 --font --n5 --n4 --n3 --n2 --n1 --nx`，另新增 `--ok --warn --err --on-pri`（主色上的文字色）、`--fs-xs/sm/md/lg/xl/2xl`、`--sp-1..6`。
- **所有 CSS 與 JS 內 HTML 不得寫死色碼**（例外：插畫 SVG 內部可用固定色，但底色、文字、框線要用變數）。
- 設定存 `App.state.ui = {theme:'system'|'light'|'dark', palette:'coral'}`；API `App.setTheme(theme, palette)`。

### 2. 單一程度設定（A 實作）
- `App.state.profile = { lv:'zero'|'n5'|'n4'|'n3'|'n2'|'n1', goals:['travel'], assist:'full'|'some'|'none' }`。
- `App.profile()` 回傳上述物件（缺欄位補預設 `{lv:'zero',goals:['travel'],assist:'full'}`）；`App.setProfile(patch)` 存檔並 `document.dispatchEvent(new CustomEvent('profilechange'))`。
- 白話名稱：zero＝完全沒學過、n5＝會五十音、n4＝會簡單句、n3＝日常會話、n2＝工作程度、n1＝接近母語。
- 舊的 world 程度、trip 難度、L1–L4 全部改讀 `App.profile()`；**程度不可再當鎖、不可讓進度歸零**。`assist` 控制提示多寡（讀音、中文、答案提示），與 `lv` 分開。
- 禮貌層級（普通／です・ます／敬語）不是程度，改成每句話旁可切換的「說法」。

### 3. 導覽與路由
- 底部導覽 5 鈕：`home` 首頁、`play` 冒險、`read` 閱讀、`kb` 知識庫、`review` 複習。手冊 `phrasebook`、特訓 `boot`、歌曲 `songs`、設定，都從首頁或各 hub 進入（`nav:false`）。
- 新路由：`kb`、`kb-page`（C）；`read`、`read-article`、`songs`、`song`（D）；`mind3d`（C，舊 3D 改名，實驗功能）。
- 首頁 `home` 由 A 新寫 `js/home.js`（`Home.render(el)`）：一個主按鈕「繼續」＋今日 3 件事（複習到期數、每日短文、冒險下一步）＋次要入口（手冊、特訓、歌曲、五十音）；首頁可點元素 ≤10。
- B 提供 `World.japan(el)`（地圖元件）與 `World.next()` → `{label, route, params}` 給首頁用。
