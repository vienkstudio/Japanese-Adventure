# 評審 v3-01：3D 心智圖（路由 `mind`）

> 評審角度：資訊視覺化＋學習工具 UX；目標使用者＝零基礎台灣學習者＋旅遊。
> 依據：`js/mind3d.js`、`js/mind-game.js`、`css/mind.css`、`data/mind/*.js` 實際統計（node 載入資料計算）。

## 2. 分級問題
**數量分布（實測）**
| 等級 | 詞彙 | 文法 |
|---|---|---|
| N5 | 718 | 88 |
| N4 | 668 | 132 |
| N3 | **2,140** | 179 |
| N2 | 1,809 | 138 |
| N1 | 2,699 | 211 |
- N3 詞彙是 N4 的 3.2 倍（tanos 舊清單特性），N3 層在圖上壓過 N5/N4，視覺重心落在零基礎者用不到的地方。
- 總覽把 5 級**同時**塞進一張圖，違反「零基礎只需 N5」的事實；應預設只顯示 N5。
- 文法套用「人事時地物」無意義：748 條中 **虛 265、事 231、物 16、地 8** → 7 個扇區極度不均，「物/地」扇區幾乎空、「虛」扇區爆滿。
- 詞彙場景 `abs（思考抽象）` 是各級最大桶（N5 137、N3 477、N1 481），成了垃圾桶；例：`青 藍色`、`赤 紅色`、`開く`、`新しい` 被標 abs（`data/mind/lex-n5.js`）。
- 旅遊相關場景過薄：N5 `travel` 僅 6 詞、`med` 7 詞——對「旅遊」目標使用者反而是最需要的。
- 18 場景×7 分區×5 級 → 431 詞群，大量 1–5 詞的碎群；分類維度太多（等級×WH×場景三軸），任何一軸都不清楚。
- 文法 `cat` 中「其他」52 條、N5 第一條 `は` 就歸「其他」；234 條無前置 → 「學習路線」其實是 `ord` 線性序列，前置網不完整。
- 等級混用兩套邏輯：詞彙＝外部 JLPT 清單、文法＝本站整理，頁尾 `mind3d.js:575` 也承認「僅供參考」，但 UI 把它當主軸呈現。

## 3. 顯示混亂的根因
1. **資料量 ≫ 畫面容量**：1,219 節點 / 375×~600px ≈ 每 180px² 一個節點，任何佈局都會糊。
2. **3D 斜視投影**把唯一有意義的軸（等級）壓扁並重疊（層距 < 投影高度）。
3. **三軸分類同時呈現**（等級＝高度、WH＝角度、場景＝外圈），使用者一次要解讀 3 個編碼且圖例在手機被藏。
4. **標籤系統估寬錯誤＋動態換籤**，字疊字且不穩定。
5. **沒有「起點」**：無預設焦點、無「你在這裡」、無建議路徑，力導向圖本質是探索工具而非學習導引。

## 4. 3D 力導向圖適合嗎？
- **不適合當主介面。** 3D 力導向擅長揭示未知網路結構（社群、引用）；本資料是**已知的層級＋序列**（等級→類別→項目；文法前置鏈），樹/清單/時間軸更準確、可讀、可點。
- 3D 的成本：WebGL 負擔、觸控難、無法閱讀文字、無障礙差、無 WebGL 退化差。
- 建議：主介面改 **2D 可逐層展開的大綱／卡片＋程度篩選**；3D 降級為「彩蛋/總覽動畫」入口（可保留於桌機「探索模式」），或直接移除以減 vendor 體積。
- 局部關聯（文法前置/後續、動詞變化）改用 Notion 式「關聯」chip 與「先學→本條→可接」步驟列，一次只顯示 1 個中心＋≤12 鄰居。

## 5. 重設計規格：Notion 式「知識庫」（取代 3D 為主介面）
### 5.1 資料模型（一個資料庫、多個視圖）
- 把詞彙＋文法＋變化攤平成單一 `Item` 陣列（Notion database 的 row），由 `data/mind/*.js` 於載入時轉換，不改原檔：
  `{id, kind:'word'|'gram'|'conj', lv, title(jp), kana, zh, scene, cat, pos, pre[], rel[], ord, status:'未學'|'學習中'|'已掌握', fav}`
- `status/fav` 存 `App.store`（沿用 `jpq.mind.v1` 的 `ST.learned`，升為三態）；屬性＝Notion property，全部可篩選/排序/分組。
- 移除「人事時地物」屬性於 UI（資料可保留）；`scene` 為單字唯一分組軸，`cat` 為文法唯一分組軸。

### 5.2 版面骨架
- 桌機 ≥960px：**左側邊欄樹（260px，可收合）＋主內容頁**；手機：側邊欄改為左滑抽屜（☰），主內容滿版。
- 側邊欄樹（巢狀頁面，toggle ▸/▾，展開狀態記憶）：
```
🏠 學習首頁
▾ 🟢 N5（已學 12/806）
    ▸ 📘 單字（718）      ← 子頁：依場景分組
    ▸ 📗 文法（88）       ← 子頁：依 cat 分組
    ▸ 🔁 動詞變化
▸ 🔵 N4  ▸ 🟡 N3  ▸ 🟠 N2  ▸ 🔴 N1   ← 預設收合
⭐ 收藏　🕘 最近開啟
```
- 頁首：麵包屑 `心智圖 / N5 / 單字 / 🚃 交通移動`，點任一段回上層。

### 5.3 主內容頁＝資料庫視圖（頁首視圖分頁＋工具列）
- 工具列：`[清單][表格][看板][畫廊]`　`篩選 ▾`　`排序 ▾`　`分組 ▾`　`🔍`　（設定存在每頁，見 5.6）。
- **清單（預設、手機唯一推薦）**：依分組顯示 toggle 區塊 `▸ 🚃 交通移動 34　▓▓░ 40%`；展開後每列 `電車 でんしゃ　電車　🔊 ☆`，列高 ≥44px。
- **表格（桌機）**：欄＝日文｜讀音｜中文｜等級｜場景/類別｜狀態｜⭐；欄頭點擊排序；虛擬捲動（只渲染可視列）。
- **看板**：欄＝狀態「未學｜學習中｜已掌握」，卡片可拖曳改狀態（手機用卡片上的狀態 chip 改，不拖曳）。
- **畫廊**：大字卡（jp 大字＋中文），點擊翻面看讀音/例句，作閃卡用。
- 每組最多先顯示 20 列＋「顯示更多」；任何時刻 DOM 列數 ≤ 60。

### 5.4 篩選／排序／分組（Notion filter chips）
- 篩選以 chip 疊加：`等級 = N5` `狀態 ≠ 已掌握` `場景 = 交通`；chip 可點改值或 ✕ 移除；「+ 篩選」下拉選屬性。
- 內建快速篩選（chip 一鍵）：「只看未學」「只看收藏」「旅遊必備」（scene ∈ trans/travel/food/shop/med）。
- 排序：`學習順序(ord)`（預設）｜五十音｜最近開啟；分組：場景｜類別｜狀態｜詞性｜無。

### 5.5 點開成頁面（Item 頁）
- 桌機：右側 peek 面板（420px，Notion 的 side peek），可「⤢ 開成整頁」；手機：直接全頁，左上 ← 返回保留捲動位置。
- 頁面內容（沿用 `renderPanel` `mind3d.js:457` 的資料）：
  1. 標題 jp 大字＋🔊＋⭐；屬性列（等級、場景/類別、詞性、狀態下拉）。
  2. 讀音、中文、例句（🔊）、💡note。
  3. toggle 區塊：`▸ 動詞變化表`、`▸ 接續`、`▸ 相近／對比`。
  4. **關聯（Notion relation）**：「先學」「學完可接」「同漢字的詞」以 chip 連結，點即開對應頁 → 取代 3D 焦點模式。
  5. 反向連結：「出現在哪些冒險世界店家/場景」連 `App.go('scene',…)`。
- URL/路由參數：`App.go('mind',{lv:'N5',view:'list',page:'gram:〜ます'})`，可分享、可返回。

### 5.6 首頁（Notion 儀表板頁）
- 頂部卡「▶ 下一步：〜ます（N5 文法 #12）[開始]」——取 `ord` 最小且未學者（沿用 `nextOf` `mind3d.js:216`）。
- 等級進度卡 5 張（N5 展開、其餘縮小）：`單字 x/718・文法 y/88`，≥80% 標示「可挑戰 N4」。
- 「今日任務」卡：沿用 `mind-game.js` 任務，但作答改卡片四選一，不再用 3D arena。
- 「🌐 3D 探索（實驗）」小按鈕：點擊才 `App.loadScript('vendor/3d-force-graph.min.js')`，預設只畫 N5。

### 5.7 實作拆分（建議檔案）
- `js/mind-db.js`：Item 轉換、filter/sort/group 純函式、視圖設定存取（`jpq.mind.views`：每頁 `{view, filters, sort, group, open[]}`）。
- `js/mind-ui.js`：側邊欄樹、麵包屑、四種視圖 renderer、peek/全頁、chips；事件代理沿用 `data-*` 模式。
- `css/mind.css`：改寫為 `.nt-` 前綴（sidebar 260px、row 44px、peek 420px、@media 720px 抽屜化）；顏色只編碼等級 `M.LV_COLOR`。
- `js/mind3d.js`：保留但改為懶載入的「探索模式」；`App.register('mind')` 改指向 mind-ui。
- 無 WebGL 不再需要特殊退化（`mind3d.js:361` 可刪）。

### 5.8 資料修正（配合重設計）
- `abs` 桶重新標註（顏色→nat、基本動詞→對應場景），目標 ≤10%；UI 顯示名改「其他」並排最後。
- 補 N5 旅遊場景詞（交通、住宿、點餐、問路、急難）每場景 ≥25 詞，可由 `data/scenes-*.js` 反向收錄。
- 文法 `cat=其他` 52 條重分類（助詞獨立成「助詞」類）；`pre` 不足 234 條 → UI 稱「建議順序」。

## 驗收標準
- 375px 首屏無重疊文字、無需旋轉/縮放即可讀到 ≥10 個 N5 詞。
- 零基礎者 3 秒內找到「下一步」按鈕；2 次點擊內聽到一個單字發音。
- 無 WebGL 裝置體驗與一般裝置一致。
- 側邊欄樹、麵包屑、四種視圖、篩選 chip、peek/全頁在 375px 與 1280px 皆可用且不重疊。
