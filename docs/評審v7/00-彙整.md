## 修正清單（依共識與嚴重度）

### P0 會教錯／方向錯
1. **挑戰過關推「下一級」方向反了**（02、06）：`js/challenge.js:544-546` 的 `LVS[indexOf-1]` 改成 `+1`。N5 過關推 N4，N1 過關不再推下一級。
2. **羅馬字仍錯**（01、05）：
   - 句子有阿拉伯數字時讀音對不齊，退回逐字轉換，出現 `made ha sensan byaku`（`js/phrase.js:180`）。
   - チェ 轉成 chie（`:231`）。
   - 名詞和數量黏在一起：`otonahitori`、`hyakugojuuen`。
   - 手冊、複習卡沒走分詞（`js/phrasebook.js:131-139`、`js/review.js:140`）。
   - 修法：全站統一使用 `Phrase.romaji`；長音寫法 dō 和 dou 擇一。
3. **新聞的本文文法與斷詞仍會教錯**（03、06、04）：
   - 文法誤判：
     - までに 判成「〜まで（甚至）」。
     - 失われようとする 判成「〜(よ)うと（不管～都）」。
     - とはいうものの 判成「〜もの（理由）」，資料庫已有的 N2 句型反而沒抓到。
     - につきまして 判成「〜につき」。
     - によって 判成「行為者」。
     - 「させていただきます」的いただきます 釋成「開動了」。
   - 修法：長句型命中後蓋掉它包含的短句型，並補排除表（`js/jp-text.js:784-805`）。
   - 斷詞拆錯：
     - 新聞：充てる 拆成 照る，実現、公約、仕組み 被拆開，「田中様」拆成「稻田＋裡面」。
     - 歌詞：いとこ 給成「堂」、ちゃ 給成「茶」、強い 讀成「し」。
     - 不存在的片語：「総選挙におく」。
   - 修法：補新聞、商務、歌詞口語詞；人名與「様」視為一組；動詞、形容詞後面接的一兩個假名不給字典意思。
4. **紅蓮華時間軸慢約 59 秒，卻標「已對時」**（04）：`js/songs.js:92` 和 `js/link-import.js:242` 呼叫 lyrics() 時沒傳影片長度，挑到錯的 LRC 版本。修法：傳入影片長度；熱門歌固定 LRC 版本；最後一句超過影片長度時提示去對時。
