## 3. 新發現
1. **高｜歌曲新聞的今日課拿旅遊句補位**：35。原因在 learn.js:264，詞不夠就用 `travelFresh` 補滿，n3 以上還先補 phrases（:223）。建議改用 N 級單字或新聞常見詞補，或者乾脆少於 8 個。
2. **高｜歌曲新聞的今日課碰不到新聞**：「用出來」固定是今日短文（learn.js:288），我的主要動機「看新聞」只能自己去閱讀分頁找。建議：應用改成「讀 1 則近三天新聞（簡單日文）」，讀完再回今日課。
3. **高｜新聞文法誤判，會教錯**：本文文法共 3 條，其中 2 條判錯。「これまで」判成〜まで（甚至），「示すとしていました」判成〜として（作為）。真正的 N2「〜を巡って」反而漏掉（49）。對補文法的人傷害最大。
4. **中｜新聞斷詞與逐詞翻譯錯**：
   - 斷詞拆錯：不透明 → 不＋透明；請け負う → 請（未收錄）＋け＋負う；ずれ込む → ずれ＋込む（擁擠）。
   - 逐詞誤譯：受けた → 參加，では → 那麼，いた → 在，しました → 做。
   - 商務信：申し上げます被拆開，「願い」→ 願望，「点」→ 分數，「ましたら」→ 增加，「ご確認いただければ」→ いた（在）＋だ＋ければ（58–59）。
5. **中｜整句當「新學」**：每張卡一整句，字放到最大，跟喇叭重疊（34）。日中同時顯示，沒有可點的詞，小測驗的干擾選項還混了「中性」（36）。這 5 句全進 SRS，明天到期 17 個（38），10 分鐘通勤做不完。建議：從句子裡挑 1–2 個新詞來學，句子只當例句。
