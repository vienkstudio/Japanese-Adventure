## 工作方式與注意
- 自測用專案的 `.claude/launch.json` 的 `jp-test`（埠 8779，獨立 origin），不要用 8765：那是使用者自己開的伺服器，localStorage 是他的真實存檔。
- 改檔後瀏覽器會吃舊快取，重載前先在頁面裡 `fetch(檔, {cache:'reload'})`。
- Bash heredoc 常失敗，多行腳本用 Write 寫好再執行。
- 平行子代理要依檔案擁有權分工，避免兩個代理改同一檔。
- 每完成一大項就 commit（中文訊息，結尾加 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`），並把 sw.js 的 VERSION 加 1。
- 不要動 `99-參考資料/`、`docs/驗收報告-v2.md`（使用者的檔）。
