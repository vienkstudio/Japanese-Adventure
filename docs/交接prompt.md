  - 截圖、腳本放 D:\reviewtmp\<組>\，測完關掉伺服器和 Chrome。
- **快取與腳本**：
  - 改檔後瀏覽器會吃舊快取。先註銷 SW、清 caches，或 `fetch(檔,{cache:'reload'})`。
  - Bash heredoc 常失敗，多行腳本用 Write 寫好再執行。
